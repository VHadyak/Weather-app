## Weather App (Not Responsive) ##
https://vhadyak.github.io/Weather-app/
#### Includes:
- ###### Daily/Hourly Forecast
- ###### Celsius/Fahrenheit conversion
- ###### API based autocomplete suggestion based on user's input
- ###### Hourly forecast timezone adjustment based on the target location
- ###### Background changes based on sun's elevation (day, evening, night)
- ###### Selecting a daily individual card will display data for that day
